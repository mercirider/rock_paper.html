# ✊✋✌️ Rock Paper Scissors Game

Ek modern aur interactive **Rock Paper Scissors (Patthar, Kagaz, Qainchi)** game jo pure **HTML, CSS aur JavaScript** mein bana hai. Koi framework nahi, koi library nahi — bas ek hi file mein poora game!

## ✨ Features

| Feature | Description |
|---------|-------------|
| ✊✋✌️ **3 Choices** | Rock, Paper, Scissors |
| 🤖 **Smart Computer** | Random choice with "thinking" animation |
| 📊 **Live Scoreboard** | You / Draws / Computer — sab track |
| 🎬 **Smooth Animations** | Card entrance, pulse, confetti |
| 🎊 **Confetti Effect** | Jeetne pe colorful confetti |
| 🌈 **Glassmorphism UI** | Modern blur + transparency |
| 💫 **Animated Background** | Floating glow circles |
| 🎮 **Keyboard Support** | R/P/S ya 1/2/3 keys |
| 🔄 **Reset Button** | Score zero kar do |
| 📱 **Fully Responsive** | Mobile, tablet, desktop |
| 🚫 **No Zoom/Scroll** | Har screen pe perfect fit |
| ⚡ **Zero Dependencies** | Pure vanilla JS |
